# Původ podkladů

## Outfit

Outfit je geometrická open-source sans-serif rodina použitá pro veškerou živou typografii webu. Je to vybraná alternativa k brandsetu; původní font brandsetu nebyl identifikován.

- [Oficiální Google Fonts specimen](https://fonts.google.com/specimen/Outfit)
- [Autorský repozitář Outfit](https://github.com/Outfitio/Outfit-Fonts)
- [Google Fonts distribuce a licence](https://github.com/google/fonts/tree/main/ofl/outfit)
- Staženo 4. října 2026 přes oficiální Google Fonts CSS API. WOFF2 soubory se servírují lokálně; obsah fontů nebyl upravován.
- `outfit-variable-0.woff2`: Latin Extended; `outfit-variable-1.woff2`: Latin. Osy váhy 100–900.
- Licence SIL Open Font License 1.1 je přiložena jako `fonts/OFL-Outfit.txt`.

## Google Play badge

- [Oficiální PNG asset Google Play](https://play.google.com/intl/en_us/badges/static/images/badges/en_badge_web_generic.png)
- [Google Play badge resources](https://play.google.com/intl/en_us/badges/)
- Staženo 4. října 2026; původní rozměry 646 × 250 px.
- Uložen jako `icons/google-play-badge-en.png`, beze změny pixelů, poměru stran a transparentního okraje. Logo a text nejsou ručně rekonstruované.
- Neaktivní podoba Bait Dash je stejný soubor zobrazený pouze pomocí CSS `grayscale(1)` a `opacity: .58`, dle zadání. Bez URL, bez klikacího elementu a bez kurzoru pointer; doplněna samostatným textem COMING SOON.
- Google Play a logo Google Play jsou ochranné známky společnosti Google LLC.

## Muonity

Herní PNG a odvozené optimalizované varianty zůstaly při polishing passu beze změny. Koncept, brandset a artworky dodal zadavatel. Třetí teaser zůstal zachován. Symbol je původní výřez z konceptu použitý v první verzi.

SEO pass přidal pouze AVIF exporty původních herních artworků: kvalita 90, vzorkování 4:4:4, šířky 416/560/672/840 px a původní šířka. Tyto exporty používají ztrátovou kompresi s vysokou kvalitou, byly vizuálně porovnány a nemění obsah, kompozici ani styl artworků. Původní PNG i všechny dřívější WebP soubory mají nezměněné kontrolní součty. Logo a favicony zůstaly beze změny.
